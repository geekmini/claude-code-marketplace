# Memory Capture - Session End

The session is ending. Capture a brief summary of significant accomplishments and learnings.

## What to Capture

**Session summary** (project-scoped):
- Major tasks completed in this session
- Key decisions made
- Problems solved and their solutions
- Changes made to architecture or patterns

**User context updates** (global):
- New preferences discovered
- Working style observations
- Updated understanding of user's expertise

## How to Capture

Use `add_memory` with a concise summary. Include:
- What was accomplished
- Any important context for future sessions
- Links to relevant files if helpful

**Scope correctly:**
- Session work summaries: use both `user_id` and `app_id`
- User preference updates: use `user_id` only

## Guidelines

- Keep summaries concise (1-3 sentences per memory)
- Focus on what would be helpful to know next session
- Don't duplicate individual task memories already saved
- Skip if session was brief or no significant work was done

## Action

Save relevant memories using `add_memory`, then allow session to end.
